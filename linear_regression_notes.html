1. Supervised Learning

Training data consists of N examples.

$$D=\{(x_1,y_1),(x_2,y_2),...,(x_N,y_N)\}$$
  • $x_i$ is the feature vector.
  • $y_i$ is the target label.
  • Objective: Learn $f:X\rightarrow Y$ so that predictions are as close as possible to the true values.
Types: Binary classification, Multiclass classification, and Regression (continuous values).

2. Measuring Prediction Quality

Regression uses Mean Squared Error (MSE). The objective is to minimize prediction error.

$$L_{MSE}=(f(x)-y)^2$$

3. Linear Regression Loss Function

Prediction:

$$\hat y=x^Tw$$
$$L(w)=\sum_{i=1}^{N}(x_i^Tw-y_i)^2$$

The loss is quadratic in the parameters.

$$L(w)=w^TX^TXw-2y^TXw+y^Ty$$

4. Unconstrained Quadratic Optimization

Minimize the loss by setting the gradient to zero.

$$\nabla L(w)=2X^T(Xw-y)=0$$
$$X^TXw=X^Ty$$

Closed-form solution:

$$w^*=(X^TX)^{-1}X^Ty$$

If $X^TX$ is not invertible, use the Moore–Penrose pseudo-inverse.

$$w^*=X^+y$$

5. Gradient Descent

Gradient descent iteratively minimizes the loss.

  1. Initialize weights.
  2. Compute gradient.
  3. Update parameters.
  4. Repeat until convergence.
$$w^{t+1}=w^t-\eta\nabla L(w^t)$$

6. Analytical Solution & Complexity

Exact inverse computation has complexity:

$$O(d^3)$$

For high-dimensional data, Gradient Descent is often preferred.

7. Gradient Descent Update for Linear Regression

$$w^{t+1}=w^t-\eta[(X^TX)w^t-X^Ty]$$
  • $\eta$ – learning rate
  • $X$ – data matrix
  • $y$ – target vector

8. Stochastic Gradient Descent

  • Uses one sample (or mini-batch) per update.
  • Scales well to large datasets.
  • Supports online learning.
  • Noise can help escape shallow minima.
  • Often converges faster in practice.

9. Probabilistic View

$$y=wx+b+\epsilon,\qquad \epsilon\sim\mathcal N(0,\sigma^2)$$
$$y\sim\mathcal N(wx+b,\sigma^2)$$

This models uncertainty, justifies squared loss using Gaussian noise, and connects regression to Maximum Likelihood Estimation.

10. Existence Theorem

An existence theorem guarantees that an optimal solution exists under suitable assumptions.

$$MSE(w)=\frac1N\sum(y_i-x_i^Tw)^2+\lambda\|w\|^2$$

11. Cross Validation

Split the dataset into k folds. Train using k−1 folds and evaluate on the remaining fold.

$$MSE=\frac1n\sum(y_i-\hat y_i)^2$$

12. Ridge Regression

Adds L2 regularization to reduce overfitting.

$$L_{ridge}(w)=\sum(y_i-x_i^Tw)^2+\lambda\sum w_j^2$$
$$\hat w=\arg\min_w\left(\|y-Xw\|^2+\lambda\|w\|^2\right)$$

13. Why Ridge Regression?

  • Prevents overfitting.
  • Handles multicollinearity.
  • Controls bias–variance tradeoff.

14. Lasso Regression

Lasso uses L1 regularization.

$$L_{lasso}=\sum(y_i-\beta_0-\sum\beta_jx_{ij})^2+\lambda\sum|\beta_j|$$

15. Why Lasso Regression?

  • Automatic feature selection.
  • Produces sparse models.
  • Prevents overfitting.
  • Improves interpretability.
